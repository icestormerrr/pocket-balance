# Архитектура

## domain

`entities/*/domain/` — типы, константы и чистые функции, описывающие предметную область: счета, категории, транзакции и переводы.

Например: тип `Transaction`, расчёт изменения баланса по операциям, проверка различия счетов перевода. Эти правила имеют смысл независимо от сценария, конкретного экрана и способа хранения данных.

## service

`entities/*/service/` — сценарии приложения: создать транзакцию, выполнить перевод, получить отчёт. Каждый публичный метод реализует один сценарий: принимает его входные данные, применяет правила, координирует чтение или изменение данных и возвращает результат или прикладную ошибку.

Логика сценария работает с `domain` и интерфейсами `I*Repository` и `I*Service`.

Service может содержать доменную логику — это допустимо. Самостоятельные чистые предметные правила предпочтительно выносить в `domain`, оставляя в service получение данных и последовательность действий сценария.

## repository

`entities/*/repository/` — получение и сохранение данных. Реализует `I*Repository`, выполняет операции с хранилищем, фильтрацию по условиям запроса и преобразование данных в предметные модели и обратно.

Скрывает детали источника данных, например `localStorage`. При сохранении контракта repository замена хранилища не должна менять сценарии и UI.

## adapter

`entities/*/adapter/` — связь UI с service через React-хуки: запросы, мутации, состояния загрузки и ошибок, кеширование и обновление связанных данных после изменений.

Adapter может подготавливать результат service для более удобного использования в UI.

## UI

Компоненты, действия пользователя, локальное состояние и композиция экранов. За прикладными данными UI обращается к adapter-хукам, без прямых вызовов service, repository и хранилища.

- `app/` — точка входа, провайдеры, роутер, layout и глобальные стили.
- `pages/` — экраны маршрутов.
- `widgets/` — более сложные независимые переиспользуемые блоки.
- `entities/*/ui/` — простые компоненты предметной области.
- `shared/ui/` — универсальные компоненты без знания предметной области.

### model

Локальная папка `model/` страницы, виджета или entity UI — чистые функции, схемы и типы для работы с предметными данными в конкретном интерфейсе.

### lib

Локальная папка `lib/` страницы, виджета или entity UI — вспомогательные утилиты, не работающие с предметной областью
